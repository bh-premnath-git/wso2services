1. ADMIN APIs - Configuration Management
=============================================================================

--- PSPs (Payment Service Providers) ---

# Create PSP
POST /admin/psps
{
  "id": "stripe",
  "name": "Stripe",
  "type": "CARD",
  "status": "ACTIVE",
  "capabilities": ["payouts", "collections", "card-only"],
  "regions_supported": ["US", "IN", "GB", "EU"],
  "metadata": {"settlement_time_hours": 24, "requires_cvv": true}
}

# List all PSPs
GET /admin/psps?skip=0&limit=100

# Get specific PSP
GET /admin/psps/stripe

# Update PSP
PUT /admin/psps/stripe
{
  "status": "INACTIVE"
}

# Delete PSP
DELETE /admin/psps/stripe


--- Corridors ---

# Create Corridor
POST /admin/corridors
{
  "id": "IN-US-INR-USD",
  "source_country": "IN",
  "dest_country": "US",
  "source_currency": "INR",
  "dest_currency": "USD",
  "status": "ACTIVE",
  "default_route_policy": "PRIORITY"
}

# List corridors
GET /admin/corridors

# Update corridor
PUT /admin/corridors/IN-US-INR-USD
{
  "status": "DISABLED"
}


--- Channels ---

# Create Channel
POST /admin/channels
{
  "id": "card_to_bank",
  "code": "CARD_TO_BANK",
  "description": "Card to bank transfer",
  "is_consumer_visible": true
}

# List channels
GET /admin/channels

  "id": "IN-US-CARD-STRIPE",
  "corridor_id": "IN-US-INR-USD",

  "min_amount": 1.0,
  "max_amount": 200000.0,

  "priority": 2,

3. INTEGRATION WITH ORCHESTRATOR + RULE ENGINE
=============================================================================

Flow:
1. User initiates payment request
2. Orchestrator calls Marketplace: POST /runtime/routing/candidates
3. Marketplace returns structured candidate list with PSPs, fees, constraints
4. Orchestrator calls Rule Engine with candidates + user context
5. Rule Engine returns: selected PSP, fallbacks, applied fees, reason
6. Orchestrator executes payment via selected PSP adapter

Example Rule Engine Input (from Orchestrator):
{
  "user": {
    "id": "user_123",
    "kyc_level": 2,
    "risk_score": 0.3
  },
  "transaction": {
    "corridor": "IN-US-INR-USD",
    "channel_code": "CARD_TO_BANK",
    "amount": 10000
  },
  "candidates": [/* from Marketplace response */],
  "context": {
    "recent_psp_failures": {
      "stripe": 0.03,
      "mastercard_send": 0.15
    },
    "system_load": {
      "stripe": "NORMAL",
      "mastercard_send": "HIGH"
    }
  }
}

Rule Engine Output:
{
  "decision": "ALLOW",
  "selected_psp": "stripe",
  "fallback_psps": ["mastercard_send"],
  "applied_fee": {
    "total": 120,
    "breakdown": {"flat": 50, "percent": 70}
  },
  "reason": "Stripe preferred: lower fee (0.5% vs 0.7%), lower failure rate (3% vs 15%)"
}
